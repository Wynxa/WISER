# Data availability

The data supporting the findings of this study are openly available in the WISER repository at:

**https://github.com/Wynxa/WISER**

The repository contains:

- the worker-centered scene graph annotations (`annotations/`),
- the safety-rule prototype library (`rules/`),
- the image-level training / development / test split lists (`samples/` and `protocol/suite_v2/`),
- the coarse and atomic candidate libraries used in the controlled retrieval experiments (`protocol/suite_v2/libraries/`),
- the evaluation configurations and scripts used to reproduce the reported results (`code/`).

The construction images are **not redistributed**, because the source ConstructionSite 10k dataset is released under a non-commercial license. Users should obtain the images from the original dataset release and combine them with the annotations and split lists provided in this repository.

A versioned snapshot of the repository will be archived with a persistent identifier upon publication.
